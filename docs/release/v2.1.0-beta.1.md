# KeyReed 2.1.0-beta.1

**Date:** 2026-11-17
**Tag:** [`v2.1.0-beta.1-rc1`](https://github.com/Shanmukh-l33t/keyreed/releases/tag/v2.1.0-beta.1-rc1)
**Branch it was built from:** `feat/hex-informed-2.1`, which contains everything from `release/2.0`
**Platform:** Windows x64. Built on Linux, cross-compiled with the llvm-mingw UCRT toolchain.

> **Before you install:** this build is **unsigned** and was **not run, tested or benchmarked** before release. Install it on a machine where you can review the first dictations. A smoke pass on a real Windows PC is still to come. Research notes are in `docs/research/`.

## What changed

### Speech recognition

- **Vocabulary now reaches the decoder.** Parakeet runs `modified_beam_search` with hotwords whenever the personal dictionary has terms, using a `bpe.vocab` built from the model's `tokens.txt` (`crates/vi-asr/src/lib.rs`). Greedy search is used when there are no terms. Before this, the terms were handed to a greedy decoder that ignores them. The `sherpa-onnx` runtime is checked first (1.12.24 or newer): an older one calls `exit(-1)` on the unknown decoding method.
- **Windowed level gate.** A 30 ms windowed test replaces the clip-average check and also accepts speech 12 dB above the clip's own noise floor, so quiet microphones are no longer dropped.
- **Polyphase windowed-sinc resampler.** A stateful Blackman-Harris sinc resampler to 16 kHz replaces the 3-tap box and linear interpolation (`crates/vi-audio/src/lib.rs`).
- **DC blocker and release tail.** A 20 Hz single-pole DC blocker runs before level and speech detection. Recording continues 200 ms after release, extended up to 600 ms while you are still speaking.
- **Two new selectable models, both SHA-256 pinned:** Parakeet TDT 110M (English, 103 MB) and Parakeet TDT 0.6B Ultra (25 languages). The catalogue now lists eight speech models in `crates/vi-asr/src/catalog.rs`; the default is unchanged (Parakeet TDT 0.6B v2).
- **Cleanup that changes less.** Filler removal keeps sentence-ending full stops, "hmm" and "ah" stay, only doubled function words collapse ("had had" stays), wording polish only runs in Professional mode, and "march" and "august" are no longer recased.

### The 2.0 work, in the same build

- **Quick Fix (Ctrl + Win + G)** works end to end: selection capture through the clipboard, a Review panel that marks every change, Enter to replace, Esc to dismiss, Undo on the pill, and a Deeper pass through the local writing model. Spelling uses the Windows spell checker; grammar uses the Apache-2.0 `gector-bert-en` int8 tagger (73 MB, downloaded once, run locally through the ONNX Runtime the app ships).
- **The Composer (Ctrl + Win + K**, or Open the Composer in the tray menu) offers Fix, Improve, Shorter, Change tone, Summarise and a typed instruction. The answer streams, Esc cancels, and a result can replace the selection, be inserted, be copied or be regenerated. Text jobs run on their own worker thread; while a language model is busy, dictation falls back to rules-only cleanup instead of waiting.
- **Style store and edit watcher** (`vi-core/src/style.rs`, `vi-core/src/editwatch.rs`) are present with their tests. Nothing calls them yet: there is no Settings page and no runtime wiring, so no text is read back and nothing is learned from your edits in this build.

### Interface

- Waveform with real meter ballistics (35 ms attack, 95 ms decay, auto level), taller bars for speech, smoother colour.
- Teal for "working" (Transcribing, Fixing), so amber means only "look at this".
- "Open privacy settings" button when the microphone fails, opening `ms-settings:privacy-microphone`.
- Setup starts the model download on Next, shows progress on every page, moves on by itself when the model is ready, and ends with a practice step that says what went wrong.
- Emerald focus ring, and a vocabulary editor with a Term row and a Sounds like row per entry.

### Windows reliability

- A 30 minute recording is processed at the cap instead of being discarded. Escape, a lost key release or a session lock still cancels.
- A held trigger key's repeats and its key-up are swallowed; modifiers resync from the OS on every key event; chords need exact modifiers; pressing another key while the trigger is held cancels the dictation.
- Clipboard history exclusion defaults on for new settings and always applies to the typing backup copy.
- Log file at `%LOCALAPPDATA%\keyreed\logs\keyreed.log`, rotated once past 1 MB, and a panic hook.
- The installer stops only KeyReed's own `llama-server.exe`.
- The manifest and icon are embedded for MSVC builds too, and a missing `windres` fails the build instead of producing a binary without them.

## What is not in this build

- Voice commands: the chord is parsed but the event is ignored, so nothing happens.
- A Settings picker for the writing model, and the "My style" page.
- Learning from your edits (the code is there, the wiring is not).
- Hook re-arm on foreground change, and the session-lock modifier reset.
- A full offline archive. Only the installer and the portable zip were built.
