## 1. Root-Cause Defects Discovered & Remediated

| # | Defect Discovered During Audit & Live Testing | Root Cause | Fix & Verification |
|---|---|---|---|
| 1 | **Local SLM (`llama-server.exe`) crashed on startup (`0xC0000142` `STATUS_DLL_INIT_FAILED`) and caused a 15-second hang on every dictation on real Windows 11** | `runtime/llama/` in v0.1.0/v0.1.1 bundled Wine stub `msvcp140.dll`, `msvcp140_1.dll`, `vcruntime140.dll`, and `vcruntime140_1.dll` from `/root/.wine/drive_c/windows/system32/`, which fail DLL initialization on real Windows 11. Additionally, `LlamaServerSupervisor::ensure_started()` polled `/health` for 15s without checking `self.is_running()`. | Replaced Wine stub CRT DLLs with genuine Microsoft-signed System32 VC++ CRT DLLs in `scripts/package-win.sh` and `dist/`. Added `if !self.is_running()` fast-exit check and session-level `startup_failed_permanently` circuit breaker in `crates/vi-rewrite/src/slm.rs`. Verified `llama-server.exe --version` exits `0` (`build 12412`) and warm Tier-1 SLM rewrite completes in `~1.40s–1.78s`. |
| 2 | **Automatic Text Insertion (`OutputMode::DirectTyping`) was disabled by default (`OutputMode::Clipboard`), and `AskBeforeInserting` never prompted or inserted** | `OutputMode::default()` returned `Clipboard`, and `OutputMode::AskBeforeInserting` in `crates/vi-app/src/main.rs` hardcoded `write_clipboard_unicode` without any prompt or target insertion. | Set `OutputMode::DirectTyping` as the default in `crates/vi-core`. Implemented `prompt_and_deliver_ask_before_inserting` (`MessageBoxW` preview + focus restoration + `SendInput` or clipboard fallback) in `crates/vi-win32/src/typing.rs`. |
| 3 | **Windows 11 Tabbed Notepad (`NotepadTextBox` -> `RichEditD2DPT`) deep editor focus discovery & focus retention** | Windows 11 Tabbed Notepad nests `RichEditD2DPT` two levels below top-level `Notepad`, and background focus restoration was blocked by Windows Foreground Lock Timeout. | Added recursive `find_deep_editor_hwnd` in `crates/vi-win32/src/context.rs` and `force_foreground_window` (`AttachThreadInput` + `BringWindowToTop` + `SetForegroundWindow`) in `crates/vi-win32/src/typing.rs`. |
| 4 | **Sentence-period capitalization corrupted filenames and domains (`auth_middleware.rs` -> `auth_middleware.Rs`)** | `capitalize_sentences_and_pronoun_i` in `crates/vi-rewrite/src/tier0.rs` set `cap_next = true` after every `.` regardless of whether whitespace followed. | Restricted sentence-boundary `.`/`!`/`?` capitalization to punctuation followed by whitespace or end-of-string. Added regression tests in `tier0.rs`. |
| 5 | **Spoken symbol replacement lowercased acronyms (`API_KEY` -> `api_key`), and `Casual` / `Concise` writing modes lacked distinct deterministic rules** | `apply_spoken_symbols` called `.to_lowercase()` before regex replacement; `tier0_clean` treated `Casual` and `Concise` identically to `Smart`. | Removed `.to_lowercase()` in `crates/vi-rewrite/src/symbols.rs`, added spoken IPv4/semver dot formatting (`10.0.0.1`), and added distinct `Casual` contraction rules and `Concise` hedge-stripping rules in `crates/vi-rewrite/src/tier0.rs`. |
| 6 | **Logo & icon assets (`assets/keyreed-logo.png`, `assets/keyreed-icon.png`) had a baked-in gray/white checkerboard background and bottom-left keycap clipping** | Commit `c19b2c8` committed rasterized checkerboard pixels into the PNG RGB channels and cropped the bottom-left corner of the keycap. | Extracted true alpha transparency from the master logo while preserving the white 3D keycap face; generated clean `keyreed-logo.png`, `keyreed-icon.png` (512x512 with generous padding), multi-size `keyreed.ico`, and embedded `KEYREED_ICON_28_BGRA` in `crates/vi-win32/src/overlay.rs`. |
| 7 | **Settings window lacked Microphone Device selector, in-UI Model Download button, and had clipped labels (`Personal Dictionary...`, `Optional Cloud API Key...`)** | `settings_wnd_proc` in `crates/vi-win32/src/ui.rs` omitted microphone selection and model download controls, used unescaped `&` mnemonics, and used narrow label widths. | Expanded Settings window (`600x660`) with Microphone Device combo box, Local Speech Engine combo box + **Download** button (with writable `%LOCALAPPDATA%\keyreed\models` fallback), Local Grammar Model combo box, escaped `&&` labels, and verified zero clipping via screenshot inspection. |
